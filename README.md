# ReminderBot 🤖

Telegram-бот для управления напоминаниями и заметками по датам. Работает в нескольких чатах с изолированными данными для каждого чата.

## Возможности

- 📅 **Гибкий ввод дат** — поддерживает множество форматов: `18.09.2026`, `вторник`, `16 января`, `26` и др.
- 🔔 **Автоматические напоминания** — ежедневная рассылка заметок в 01:00 (воскресенье — на неделю вперёд, остальные дни — на 2 дня)
- 👥 **Многопользовательский режим** — изолированные данные для каждого чата
- 🔐 **Администрирование** — управление чатами, загрузка/выгрузка базы данных
- 📝 **Простое управление** — добавление, просмотр и удаление заметок

## Команды

### В разрешённых чатах

| Команда | Описание |
|---------|----------|
| `/ping` | Проверка работы бота + показывает ID чата |
| `/add <дата>: <текст>` | Создать заметку на указанную дату |
| `/get <дата>` | Получить заметки на конкретную дату |
| `/get <дата>-<дата>` | Получить заметки за диапазон дат |
| `/get <дата>-` | Получить заметки от даты и далее |
| `/get -<дата>` | Получить заметки с сегодня до указанной даты |
| `/getall` | Все заметки начиная с сегодня |
| `/remove <дата> <номер>` | Удалить заметку по номеру |
| `/clean` | Удалить все сообщения бота в текущей сессии |
| `/help` | Справка по командам |

### Для администратора (в любом чате)

| Команда | Описание |
|---------|----------|
| `/load` | Скачать файл с базой заметок |
| `/upload` + файл | Заменить файл базы заметок |
| `/chats` | Список разрешённых чатов |
| `/addchat <id>` | Добавить чат в белый список |
| `/removechat <id>` | Удалить чат из белого списка |

## Форматы дат

| Формат | Пример | Особенности |
|--------|--------|-------------|
| Полная дата | `18.09.2026`, `18.09.26` | Работает с прошедшими датами |
| Обратный формат | `2026.12.28` | Работает с прошедшими датами |
| День и месяц | `18.08` | Автопереход на следующий год, если в текущем году дата уже прошла |
| Только день | `9`, `26` | Автопереход на следующий месяц, если в текущем месяце этот день уже прошёл |
| День недели | `вторник`, `сб` | Ближайший такой день |
| День + месяц словами | `16 января`, `23 июл` | Автопереход на следующий год, если в текущем году дата уже прошла |

## Установка и запуск

### Требования

- .NET 11.0 SDK
- Токен Telegram-бота (получить у [@BotFather](https://t.me/BotFather))

### Быстрый старт

1. Клонировать репозиторий:
```bash
git clone <repo-url>
cd ReminderBot
```

2. Настроить конфигурацию (один из способов):

**Через config.json:**
```json
{
  "Token": "your-bot-token",
  "AdminChatId": -123456789,
  "NotesFileName": "notes.txt"
}
```

**Через переменные окружения:**
```bash
# Windows PowerShell
$env:BotConfiguration__Token="your-token"
$env:BotConfiguration__AdminChatId="-123456789"

# Linux/macOS
export BotConfiguration__Token="your-token"
export BotConfiguration__AdminChatId="-123456789"
```

**Через User Secrets:**
```bash
dotnet user-secrets init
dotnet user-secrets set "BotConfiguration:Token" "your-token"
dotnet user-secrets set "BotConfiguration:AdminChatId" "-123456789"
```

3. Запустить:
```bash
dotnet run
```

## Архитектура

- **TelegramBotBase** — базовый класс для polling и отправки сообщений
- **Bot** — основная бизнес-логика, команды, планировщик
- **DateNote** — модель заметки с парсингом дат

Данные хранятся в файле `notes.txt`:
```
#allowed_chats: -1001980667668, -1001234567890
15.02.2025: Встреча с клиентом (от 08.02.2025) [#-1001980667668]
16.02.2025: Позвонить маме (от 10.02.2025) [#-1001234567890]
```

## Безопасность

- При загрузке нового файла (`/upload`) создаётся резервная копия (`notes.txt.backup`)
- Админский чат нельзя удалить через `/removechat`
- Каждый чат видит только свои заметки
